# THIS REPOSITORY IS A FORK

It is forked from POLARIS, the POLArized RadIation Simulator of CAU Kiel.

Main purpose of this fork is the restructuring of code, as well as a
slight runtime-optimization where ever possible.

Currently, only the text- and data parser of POLARIS are "under construction".

*Important*: I am no physicist! All recommendations are purely made
from a coding-point of view.
